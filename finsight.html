Case Study · Fintech / Product

FinSight

Turning financial transactions into actionable insights through analytics, automation, and responsible ML.

Independently built a full-stack personal finance platform featuring transaction management, automated CSV ingestion, financial analytics, and recurring-payment detection. Developed ML categorization experiments, identified misleading performance metrics, and designed human-in-the-loop workflows to improve reliability.

Independent Developer / Product Owner

GitHub Repository

The Problem

Personal finance tools often prioritize dashboards over data integrity. CSV imports fail silently, categories lack provenance, and ML demos inflate accuracy with evaluation shortcuts that do not survive real merchant overlap. I wanted a local, interview-ready system that treats money as decimal-safe data and keeps ML claims honest.

What I Built

  • Account and transaction management with signed amounts and category review.
  • CSV ingestion with validation, partial success, and deduplication.
  • Spending and cash-flow analytics, including month-over-month comparisons.
  • Category and merchant analytics computed from PostgreSQL via FastAPI.
  • Deterministic recurring-payment detection from transaction history.
  • User category correction workflow with explicit category provenance.
  • Offline ML transaction-classification experiments (not wired into the live API).

Key Decisions

During evaluation, conventional random train/test splitting inflated model performance because of merchant overlap. I introduced merchant-grouped evaluation and established minimum-data requirements before any model deployment.

Real trusted labels in the dataset were insufficient for meaningful training. The classifier was intentionally not integrated into the live application. Automatic ML categorization is an offline experiment — not a shipped feature.

Results & Impact

Full-stack Next.js UI over a FastAPI + PostgreSQL backend
Provenance Category source tracked as user, CSV, rules, model, or unknown
Honest ML Merchant-grouped evaluation exposed optimistic random-split metrics
Local-first Single-user portfolio system — no fabricated adoption or revenue metrics

FinSight is a local portfolio application with no public production deployment. There is no live demo URL by design.
